# research/

One-off analysis scripts, oversized data and OWNER-FACING design documents
(image-prompt sheets, audits, expansion specs) — NOT bundled with the app,
not part of the runtime dependency graph. `.venv/` under `ephemeris/` is a
local Python 3.11 virtual environment (gitignored) — ignore it entirely.

| `build_relocation_manifest.py` | Algorithmic | RESTRUCTURE Phase 1's relocation-map generator — [about](__about/build_relocation_manifest.md) · [flow](__flow/build_relocation_manifest.md) |

| `rewrite_sheet_paths.py` | Algorithmic | RESTRUCTURE Phase 2 — rewrites prompt-sheet drop paths onto the new tree — [about](__about/rewrite_sheet_paths.md) · [flow](__flow/rewrite_sheet_paths.md) |
