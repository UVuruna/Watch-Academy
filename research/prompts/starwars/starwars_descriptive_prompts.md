# Star Wars — Descriptive Variants (Copyright-Safe Wording)

**Owner plan, 2026-07-26.** The original sheet
([Star Wars Prompts](starwars_prompts.md)) keeps getting REFUSED by
ChatGPT/Gemini because its prompts name protected characters and
franchise terms directly ("Obi-Wan Kenobi", "lightsaber", "Jedi"...).
This file is a **review candidate**: the SAME 30 figures, the SAME
composition template (badge framing, registers, frame motifs, day-glyph
roundels, palette, house rules — all inherited from the parent sheet,
not restated here), but every figure is conveyed through PURE
physical/visual description — species traits, build, face, clothing,
weapon shape and color, pose, aura — with ZERO character names, titles,
or trademarked terms. The goal is a generator-accepted prompt that still
draws a recognizable likeness through description alone.

**If the owner approves:** generated results land as `_v2` versions of
the same figure stems (`ObiWan_v2.png` beside `ObiWan.png`, etc.), in
the same `primary/`/`colored/` folders as the parent sheet, and either
rotate with or replace the image-reference variants once the verdict is
in. Nothing here changes the parent sheet — it is untouched.

**Do not copy commentary from this file into the parent sheet, and vice
versa** — this file's only job is the wording substitution; every other
doctrine question (registers, rotation, title plates, art status) is
answered in [Star Wars Prompts](starwars_prompts.md).

## Substitution key (reference only — never sent to the generator)

| Forbidden term/name | Descriptive substitute used below |
|---|---|
| Jedi (order/temple) | "an ancient monastic order of warrior-sages" / "the sage order" |
| Sith / Imperial (order) | "a shadow regime" / "the ruling regime" |
| lightsaber / lightsaber hilt | "energy blade" / "blade hilt" |
| the Force / Force-glow | "an unseen inner power" / "a faint inner-energy glow" |
| Aurebesh(-flavored) | "invented-glyph" (script flavor, non-legible) |
| kyber(-blue) | "glowing blue" |
| Millennium Falcon / "the Falcon" | "a battered saucer-shaped freighter ship" |
| stormtrooper / trooper | "armored foot-soldier" / "soldier" |
| First Order / Empire / Imperial | "the regime" / "the ruling regime" |
| Mandalorian armor | "clan-forged bounty-hunter armor" |
| Death Star | "a moon-sized battle station" |
| Dagobah / Naboo / Exegol (named) | terrain described, planet never named |
| bowcaster | "a heavy crossbow-style ranged weapon" |
| wookiee | "a towering, shaggy-furred beast-warrior" |
| Star Destroyer | "a vast wedge-shaped warship" |
| Grand Moff | "regime governor" |
| Council (Jedi Council) | "an order's own seal-medallion" (object only, no institution name) |
| Character names (all 30) | physical/role description only; named ONLY in this file's own headings, for the owner's mapping — headings are never sent to the generator (only the fenced prompt text is, per PromptPainter's sheet contract) |

Every fenced prompt below is a complete, self-contained brief — nothing
in it depends on reading the parent sheet or this table.
