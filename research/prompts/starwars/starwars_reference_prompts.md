# Star Wars — Reference-Image Variants (attach the figure, prompt the badge)

**Owner plan, 2026-07-26 — the SECOND of the two agreed routes.** The
parent sheet ([Star Wars Prompts](starwars_prompts.md)) gets REFUSED
because it names protected characters; the first workaround describes
each figure in words ([Star Wars Descriptive Prompts](starwars_descriptive_prompts.md),
`_v2` stems). **This sheet is the other route:** the prompt describes
EVERYTHING EXCEPT the figure — medallion, register, frame motif,
day-glyph roundels, pose, staging, palette — and the figure itself
arrives as an **attached reference image** the generator composites into
the scene. No name, no franchise term, no physical description needed:
the likeness comes from the picture.

**Which route wins is the owner's verdict.** Either one survives alone,
or both stay and rotate as `_vN` siblings of the same stem (the
universal rotation convention — the dial picks by date), exactly as
[Scale Badge Prompts](../badge/scale_badge_prompts.md) already does for
Judas/Lucifer.

## How to run this sheet

1. **Attach the reference file named in each entry's `Attach:` line**
   — they live in the owner's local `UV/sw_reference/` folder (26 PNGs,
   gitignored, never committed: they are third-party stills kept for
   the owner's own compositing, not project art).
2. **Type/paste the fenced prompt** exactly as written. It never names
   anyone — it points at "the attached figure".
3. **Drop the result** at the path in the entry's arrow line (`_v3`
   stems — v1 = the parent's named prompts, v2 = descriptive, v3 =
   this reference route).

**Stem convention:** `<Figure>_v3.png` beside `<Figure>.png` and
`<Figure>_v2.png`, in the same `primary/bronze/` and `primary/colored/`
look folders the parent sheet uses (the tree law, `assets/___assets.md`).

## Vocabulary law (inherited)

The fenced prompts below carry **zero** protected names and zero
franchise terms — the same substitution key
[Star Wars Descriptive Prompts](starwars_descriptive_prompts.md)
establishes (energy blade, monastic order, the regime, invented-glyph
ornament, glowing blue). Markdown headings outside the fences keep the
real names so the owner can map figure → stem; PromptPainter only ever
types the fenced text, never a heading.
