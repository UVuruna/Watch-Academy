# prompts/weekday/

One complete image-generation sheet per weekday theme — every plate the
theme needs across both rosters (Planetary + Pantheon, where it has both),
in every register it ships (bronze + colored), including the Sunday dual
and the Ninth. Check [Roster](../../../ROSTER.md) for what is already on
disk per source before generating.
