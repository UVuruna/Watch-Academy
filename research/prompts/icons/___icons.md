# prompts/icons/

Small SVG icon requests for spots where an emoji is not adequate (or
collides with an already-used sun/moon glyph). OWNER-FACING generation
instructions, written in Serbian by the owner's explicit order (2026-07-19)
— an approved exception to the English-only rule; agents read the file list
and drop paths, the prose is for the owner, and is left untranslated.

## Files

| Sheet | One line |
|-------|----------|
