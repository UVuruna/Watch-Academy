# The Registry's Sentinel

**Script:** [Sentinel (script)](../sentinel.py)

## Purpose

`COMPUTED` — the marker for a value the registry REFUSES to freeze.

The Continents' seat stems ARE the dial's own Earth faces, built from
`continents.CONTINENTS_REGIONS` at derivation time (Rule #19: compute,
don't generate). Writing them into the registry would be the same
mapping in a second place, and the second place is always the one that
goes stale.

Its own module so every group table under [week/](../week/___week.md)
can import it without importing its siblings.

Layer: config — pure, imports nothing.
