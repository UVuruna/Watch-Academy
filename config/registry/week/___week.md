# config/registry/week/

THE WEEK REGISTRY's data — the 6+3 kind, one entry per theme, split one
file per GROUP along the project's own hierarchy
(`taxonomy.WEEK_GROUPS`, the same grouping the asset tree and the
Encyclopedia halls use). A theme's entry therefore sits in the file its
art sits under, and no file approaches THE STRUCTURE LAW's threshold.

Layer: config — pure DATA. Nothing here imports anything but the
sentinel.
