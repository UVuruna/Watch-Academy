# Pocket Watch

This folder is the future home of the Kotlin, native-Android phone edition
of the DOMY dial. Its founding session has not run yet — this file only
carries the name story and points at the charter that governs it.

## The Name

**Pocket Watch** (owner's pick, 2026-08-11). Watch Academy stays the
desktop edition; the phone carries its own name.

The phone is this century's pocket — and the watch moves back in. Pocket
Watch puts the full DOMY dial on the home screen, the way a pocket watch
once rode a waistcoat.

## Where the law lives

Every sealed decision for this project — the technology choice (Kotlin,
native, no KMP/Flutter/embedded Python), the widgets, the bakery and
CONTRACT PACK, the base pack agreement, THE PARITY LAW — is recorded in
[../ANDROID.md](../ANDROID.md). Read it before any phone-related work; this
README is not a substitute for it.

The founding session still runs the formal START rules (scaffold, guards,
registration, logo) — the name itself is already decided and is not
reopened.
