# illustrator/

Adobe Illustrator vector sources for skin assets — NOT bundled with the app.
Final assets are exported from here into
[Assets (folder)](../assets/___assets.md) as SVG/PNG.

## Files

- `Clock 24h.ai`, `Clock.ai`, `Clock_small.ai` — dial variants
- `Clock_Circle.ai`, `Clock_OuterColors.ai` — ring and sector coloring
- `AnnoLucis.ai` — lettering/wordmark artwork
- `Pointers.ai` — pointer/hand vector source
- `Ring.ai` — ring face/letter vector source
- `Separation.ai` — layer-separation working file (purpose not
  cross-referenced elsewhere; owner scratch)
- `compass.ai` — compass icon vector source
- `cube.ai` — Cube Canon diagram vector source
- `UI rework I.ai`, `UI rework I - FINAL.ai` — a UI rework pass, draft
  and final
